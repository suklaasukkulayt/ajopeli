# DIY ARCADE MACHINE + KuuppaKart 1  

This is the GitHub repository for the **DIY Arcade Machine** made for [Stardance](https://stardance.hackclub.com/projects/30991) and for the [**KuuppaKart 1**](https://play.unity.com/en/games/4a235e58-f486-49cd-8fb5-33baa10e1e9a/kuuppakart-1) driving game I made that is used for the Arcade Machine.  

## KuuppaKart 1:  
You can **download** KuuppaKart for **Linux** and **Windows** (64-bit) machines, or **play in your browser** from [here](https://play.unity.com/en/games/4a235e58-f486-49cd-8fb5-33baa10e1e9a/kuuppakart-1). You can find the **controls** at the [**Releases**](https://github.com/suklaasukkulayt/kuuppakart.arcade-machine/releases) tab or in the **Unity Play** description.  
I made this game in coding class a while back and now I updated it for the DIY Arcade Machine.
